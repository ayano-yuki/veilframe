# veilframe レビュー

`../../docs/decisions.md`と関連する`../../docs/ard/`の判断を確認する。

## インターフェイス

動画再生・ライセンス取得・記録保存について、次を実装とテストで照合する。

- 入出力の契約、失敗の分類、キャンセルと終了処理。
- 連続操作・遅れて完了する処理・破棄済みインスタンスによる状態上書き。
- サーバー秘密情報・動画URLの記録、エクスポート、ログへの混入。
- 本番実装とテスト用実装で、成功・失敗・終了時の観測可能な振る舞いが一致するか。
- 保存とインポートで部分書き込みが発生しないか。

レビュー結果と未解決事項をdocsに記録する。設計変更の判断と代替案は日付付きのdocs/ardに置く。合意されていない機能・依存を追加しない。

## UI

PC幅・モバイル幅の画面操作を検証し、主要画面、再生の主要状態、エラー、記録詳細、削除確認を撮影する。画像はGitHub Actions成果物に保存し、許可されたPRコメント更新のワークフローでリンクする。

UI用のテスト再生をWidevineの実機検証と混同しない。実機のOS・Chrome・ハードウェアとキャプチャ方法を明示する。未検証の保護挙動を保証しない。

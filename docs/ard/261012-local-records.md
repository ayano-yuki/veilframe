# ブラウザ内記録とZIP交換

状態：採用。利用者との一問一答で決定。

## 決定

idbを使ったIndexedDBに記録と画像を保存する。fflateでJSONと画像のZIPをエクスポート・インポートする。動画URLやライセンス認証情報は保存しない。独自接続の画面設定も永続保存しない。

全インポート内容を検証してから一括保存する。不正な項目があれば何も取り込まない。既存IDは上書きせずスキップする。削除は確認後に記録と画像を一緒に削除する。

## 理由と代替案

サーバー保存と認証・保存基盤の追加は採用せず、端末内保存を選択した。画像を個別に比較できるZIPを選び、Base64を埋め込んだ単一JSONは採用しない。端末間で記録を移すためインポートも含める。

## 影響

形式・画像数・容量・展開後サイズ・記録数を保存前に検証する。IndexedDBのトランザクションで部分書き込みを防ぐ。保存失敗や容量不足は利用者に表示する。

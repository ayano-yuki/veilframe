# ライセンス取得の境界

状態：採用。利用者との一問一答で決定。

## 決定

ライセンス取得はNuxtサーバー経由とし、許可済みURLだけに送信する。接続先URLと認証ヘッダーはruntime configのサーバー専用設定に置く。HTTPリダイレクトは拒否する。転送は15秒でタイムアウトし自動再試行しない。要求・応答は各1MBまで。

公開はログインなしのVercelを予定する。公開サイトでは公開テスト素材のみを許可する。独自接続は既定で無効とし、ローカルで明示的に有効化する。Vercelでは設定にかかわらず独自接続を拒否する。

## 理由と代替案

直接接続では秘密の認証情報をブラウザに渡す必要があるため採用しない。公開サイトで独自接続を提供すると匿名利用者が設定済み認証情報を使用できるため、ローカル限定を選択した。許可ホスト内の自由なパス入力よりも、URL単位の許可を選択した。

## 影響

API入口、転送ロジック、接続設定、外部通信を分離してテストする。エラーの表示や記録に秘密を混入させない。

# インターフェイス実装レビュー

## レビュー対象と結果

| 契約                      | 確認した内容                                                                                     |
| ------------------------- | ------------------------------------------------------------------------------------------------ |
| PlaybackPort / controller | 条件のスナップショット、生成・ロード・破棄失敗、世代変更、古い結果の抑止、非対応エラーの分類     |
| RecordRepository          | 保存と画像の一致、再接続、日時順、確認後の削除、重複の既存優先、全件検証、トランザクションの中止 |
| LicenseTransport          | 接続先選択、秘密ヘッダーの付与、要求・応答サイズ、リダイレクト拒否、15秒中止、再試行なし         |
| ZIP入出力                 | バージョン、未知フィールド、重複ID、余分なファイル、不足画像、展開サイズ、件数、容量超過         |
| UI用再生実装              | load/destroyの同じ契約、成功・失敗・非対応の再現、Vercelでは差し替え無効                         |

## レビューによる修正

- ライセンス要求を全体読み込み後に制限する実装から、ストリーム途中で容量制限する実装に変更した。
- ローカル用の動画URL初期値を公開runtime configからサーバー専用設定へ移した。公開環境へ返さないことをテストした。
- SSR直後の未接続のボタン操作を防ぐため、onMountedまで再生・保存を無効にした。
- Shakaの要求構成非対応エラーを、一般的な通信・再生失敗から区別して記録するようにした。
- 古い生成・ロード結果と部分インポートのケースをテストし、状態上書きと部分保存を防いだ。

## 検証の境界

外部サービスの接続と実機の保護経路は、ポートのモックで実証しない。Windows・Androidの実機Widevine再生、OS撮影、Vercel公開、GitHub上のPR投稿は未実施。実施時は端末・OS・Chrome・観測結果を記録する。
